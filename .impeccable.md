# Impeccable — Mental Math Trainer

Design context for `mental-math-trainer` (REFLEX_CORE). All future UI work in this repo should read this file first.

## Design Context

### Users

Founders, operators, PMs, and CFO-adjacent folks who need to run mental math **during a live conversation** — pricing, hours to monthly, break-even, runway, dilution, TAM. Session is short (five minutes). No calculator. Never LIVE — every number is a **SAMPLE**.

### Brand personality

Focused. Honest. Quiet.

- Says "SAMPLE" out loud on every prompt.
- Names the shortcut before the number.
- No trophies, no confetti, no streak popups.

### Aesthetic direction

Warm dark editor. Cream text on near-black warm brown. One amber accent (`--link`) for every action. Tag colors only appear on tags, never in chrome.

References: `context/apps/leetcode-coach` for tag popovers and per-card chips. `context/apps/Stocks-Trainer` for the session-peek banner.

Anti-references: mosaic chip walls, colorful gamified dashboards, animated confetti, "you're on fire" motion.

### Design principles

1. **Status at a glance** — applied tags render inline on every card. No `<details>`, no click required to know what needs work.
2. **One accent, one intent** — amber = tap here. Tag colors stay inside tags. Coach panels use warm/red only for wrong.
3. **Filters live in popovers** — a single `Filter` button opens grouped tag rows (swatch + label). Never a mosaic of chips in the page flow.
4. **Numbers are typography** — monospace for drills, timers, and answers. Sans for prose and lessons.
5. **Every interactive gets a visible focus ring**. Every disabled control says why.

### Layout system

- Column max-width `42rem`, page padding `2.5rem 1.25rem`.
- Radius `6px`. Border color `--panel-edge`. Panel bg `--panel`.
- Spacing scale: `0.35rem / 0.6rem / 0.85rem / 1.25rem / 1.75rem`.
- Popover panel `min-width: 18rem`, `max-width: 22rem`, `max-height: 22rem`, absolute below trigger.

### Do not

- Do not restore `/archive` as a learner surface.
- Do not add per-card `<details>Tag</details>` collapses.
- Do not render every tag as a full-width chip in the page flow.
- Do not use tag colors for buttons, borders, or headings.
