
### 🧾 **Cloud Infrastructure Costs**

- **Third-party Software Licenses/Integrations**
- **Customer Support**
- **DevOps/SRE Costs (proportional)**
- **Transactional Fees**
- **Other Direct Costs to Serve the Product)**  ÷  **Total Active Paying Users (Optional for Unit Cost)**

---

### 💡 COGS Categories for SaaS Startup

| **Category**                        | **Examples**                                                         |
| ----------------------------------- | -------------------------------------------------------------------- |
| **1. Hosting/Cloud Infra**          | AWS, Azure, GCP, server bandwidth, storage                           |
| **2. Software Licensing**           | APIs, SMTP providers (like SendGrid), Stripe fees, monitoring tools  |
| **3. Support & Success**            | Salaries of customer support (only proportional to service delivery) |
| **4. DevOps / SRE**                 | Salary % of engineers maintaining uptime/deployment pipelines        |
| **5. Transactional Costs**          | Credit card fees (e.g., Stripe ~2.9% + $0.30/txn), SMS fees          |
| **6. Direct Professional Services** | Onboarding teams or integration help if bundled into service         |

---

### 🧮 **SaaS Startup Example Calculation**

Let’s say your monthly COGS looks like this:

|**Item**|**Monthly Cost**|
|---|---|
|AWS (Compute + DB + S3)|$500|
|SendGrid Email API|$100|
|Stripe Transaction Fees|$300|
|Customer Support Salaries (allocated)|$1,000|
|LogRocket/Monitoring|$200|

**Total COGS = $2,100/month**

If you have **100 paying customers**,  
**COGS per customer = $2,100 / 100 = $21/user/month**

### ✅ Notes

- **Exclude**: Engineering time for _new features_, marketing, sales, founder salary, etc.
- **Include** only what’s **required to keep the service running for existing customers**.
- Your **gross margin** = (Revenue - COGS) ÷ Revenue.  
- SaaS targets ~80–90% gross margin.
	- Because software has low incremental costs per user (i.e., low COGS).
	- COGS typically includes cloud infrastructure, support, third-party API fees, etc.
- Typical SaaS COGS Components (that make up that 10–20%):
	- **Cloud infrastructure costs** (e.g., AWS, Azure, GCP)
	- **Third-party service/API fees** (e.g., Stripe, SendGrid, Algolia)
	- **Customer support salaries** (if support is included in COGS accounting)
	- **Software licensing or embedded tools**
	- **Hosting and DevOps tooling**
	- **Data storage and bandwidth costs**
