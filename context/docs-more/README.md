# Extra lessons (`context/docs-more`)

Original teaching notes that fill gaps in `context/docs/_Biz Math/`. The trainer does **not** paste these files into the UI. Agents rewrite them into guide bodies, shortcuts, drills, and cases (`familyId` below).

Do not duplicate the original ladder (anchors, magnitude, percent shortcuts, ÷5, ×720, break-even, markup, stacked founder, LTV ≥ 3× CAC). Those stay in `context/docs/`.

## Why this folder exists

| Gap in `context/docs/` | Filled here |
|------------------------|-------------|
| Percent and scale tricks, but little **raw arithmetic** (add left-to-right, round-and-adjust, doubling) | `Mental Math/` |
| SaaS names (MRR, churn, NRR) listed, but not **on-the-fly formulas** | `Startup Math/` |
| No Rule of 40, burn multiple, processing fees, dilution, Fermi TAM | `Startup Math/` |
