# Nearby square, then bump

You rarely need a perfect square root. You need a number that is close enough to smell-test an area or a geometric mean.

## The bump

If N = a² + d, then

√N ≈ a + d / (2a)

√104: 10² = 100, leftover 4. 4 / 20 = 0.2 → **10.2**

(Actual √104 ≈ 10.198. Good enough to talk.)

If N is a little *under* a square, d is negative and you subtract the bump.

## One Babylonian step

Guess x. Replace it with the average of x and N/x:

(x + N/x) / 2

√10, sloppy guess 3: 10/3 ≈ 3.33, and (3 + 3.33) / 2 ≈ **3.17**. The true root is 3.162, so one step already lands within 0.01.

Use it when the number is not near a square you know. A perfect square needs no step at all.

A second pass is rarely worth it in conversation.

## Conversation use

“Is this closer to 10 or 11 on a side?” is a bump off 100. Do not open a calculator for a fence-length smell test.

## Same idea, new numbers

- √103 → 10 + 3/20 = 10.15
- √85 → 9 + 4/18 ≈ 9.22 (9²=81)
- √10 from guess 3 → (3 + 3.33)/2 ≈ 3.17
