# Add the same to both sides

Subtraction does not change when you add **c** to both numbers:

a − b = (a + c) − (b + c)

Push the number you are subtracting onto a round 10, 100, or 1,000, and the other side comes along.

## 502 − 198

198 wants 2 to become 200. Add 2 to both:

504 − 200 = **304**

## 725 − 397

Add 3: 728 − 400 = **328**

## Why operators use this

“Cash $1,003 minus a $198 refund” is painful in columns. Add $2 to both: $1,005 − $200 = **$805**. You never borrow across zeros.

This is a different move from round-then-compensate (that one rounds one side and pays back). Here **both** sides move.

## Same idea, new numbers

- 600 − 198 → 602 − 200 = 402
- 1,003 − 198 → 1,005 − 200 = 805
- 340 − 97 → 343 − 100 = 243
