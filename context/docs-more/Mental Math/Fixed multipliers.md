# Fixed multipliers

Some multipliers show up so often that each one deserves a reflex. Every row below turns the multiplier into a double, a shift, or a small add or subtract.

## Three families inside the table

**Neighbors of a round number.** ×9, ×19, ×99, ×999 are “round, then minus one copy.” ×11, ×101, ×1,001 are “round, then plus one copy.” 42 × 19 = 840 − 42 = **798**.

**Fractions of a power of ten.** ×5 = ×10 ÷ 2. ×25 = ×100 ÷ 4. ×50 = ×100 ÷ 2. ×75 = ×100 × ¾. ×125 = ×1,000 ÷ 8. You trade a multiply for a shift and an easy divide.

**Small builds.** ×3 = ×2 + ×1. ×6 = ×5 + ×1. ×12 = ×10 + ×2. ×15 = ×10 + ×5 (and ×5 is half of ×10). ×18 = ×20 − ×2.

## Eleven, all the way

Two digits: put the digit sum in the middle. 43 × 11 → 4 | 4+3 | 3 → **473**. Carry when the middle is 10+.

Longer numbers: first digit, each adjacent pair sum, last digit. 347 × 11 → 3 | 7 | 11 | 7 → carry → **3,817**. This neighbor rule is the simplest of the Trachtenberg-style digit rules.

## Trachtenberg digit rules: ×12, ×6, ×7

Jakow Trachtenberg (1888–1953), an engineer from Odessa, built a set of digit-by-digit multiplication rules. The 1960 book The Trachtenberg Speed System of Basic Mathematics (Ann Cutler and Rudolph McShane) says he worked the system out while held in Nazi camps. That story comes from the book itself and is not independently documented in detail. The rules are not secret: each one is a row of the table above, done one digit at a time.

Every rule runs the same way:

- Put a 0 in front of the number.
- Work right to left. The **neighbor** is the digit to the right (0 past the end).
- Write one digit per step and carry the rest left.

| × | Each digit becomes | Why it works |
|---|--------------------|--------------|
| 11 | digit + neighbor | ×10 + ×1 |
| 12 | double the digit + neighbor | ×10 + ×2 |
| 6 | digit + half the neighbor (drop any half), +5 if the digit is odd | ×1 + ×5; ×5 is half of ×10 |
| 7 | double the digit + half the neighbor, +5 if the digit is odd | ×2 + ×5 |

The “half the neighbor, +5 if odd” part is ×5 written in place: half of each digit lands one place to the left, and an odd digit leaves a 5 behind.

SAMPLE: 347 × 12, written as 0347.

- 7: 2 × 7 + 0 = 14 → write 4, carry 1
- 4: 2 × 4 + 7 + 1 = 16 → write 6, carry 1
- 3: 2 × 3 + 4 + 1 = 11 → write 1, carry 1
- 0: 0 + 3 + 1 = 4 → **4,164**

SAMPLE: 342 × 6, written as 0342.

- 2: 2 + 0 = 2
- 4: 4 + half of 2 = 5
- 3: 3 + half of 4 + 5 (3 is odd) = 10 → write 0, carry 1
- 0: 0 + half of 3 (1) + 1 = 2 → **2,052**

SAMPLE: 342 × 7 → 2 × 2 = 4; 2 × 4 + 1 = 9; 2 × 3 + 2 + 5 = 13 → 3, carry 1; 1 + 1 = 2 → **2,394**.

In conversation the table builds (×12 = ×10 + ×2) are usually faster. The digit rules earn their keep on long numbers on paper or a whiteboard, where you write the answer once, right to left, with no partial products.

## ×1001 and ×101 park copies

38 × 1,001 = 38,000 + 38 = **38,038** — the number written twice with a zero gap. 47 × 101 = **4,747**, the two-digit number written twice.

## Conversation use

$37 a seat for a 12-person team is 370 + 74 = **$444**. A $19 add-on for 42 accounts is 840 − 42 = **$798**. A 15% fee on $46 is the ×15 row shifted: 6.90.
