# Burn multiple

How many dollars of **net burn** did you spend to add a dollar of **ARR**?

> burn multiple ≈ net burn / net new ARR

Net burn is cash out minus cash in for the period. Net new ARR is ending ARR minus starting ARR (for that period).

## Shapes

- 1×: spend $1 to add $1 ARR (efficient)
- 2×: common while scaling
- 5×+: you are buying revenue expensively — or the ARR add is tiny

Example: burn $2M this year, ARR went from $3M to $4M (+$1M) → multiple = **2×**.

## Sign

If ARR fell, the multiple is meaningless or infinite. Fix retention first.

## Conversation use

“We only burned 800k and added 200k ARR” → **4×**. Not a badge.

## Check

- Burn 1.2M, new ARR 600k → 2×
- Burn 500k, new ARR 500k → 1×
