# Fully loaded headcount

Salary is not the cost of a person. Load benefits, payroll tax, tools, and management overhead.

The original patterns file uses **×1.3** as “always add 30%.” Same idea:

> loaded cost ≈ salary × 1.25 to 1.4

Use **×1.3** as the default mental move unless you know a tighter number.

## Examples

- $120k salary → ×1.3 ≈ **$156k**
- Five engineers at $150k → 750k salaries → ×1.3 ≈ **$975k** fully loaded

## Contractors

A $150/hr contractor × 160 hours ≈ $24k/month ≈ $288k/year **without** the 1.3× (they price in their own load). Compare apples to loaded FTE, not to salary.

## Conversation use

“We hired ten people at 100k” is not a $1M cost line. It is about **$1.3M**.

## Same idea, new numbers

- $80k × 1.3 = $104k
- $200k × 1.3 = $260k
